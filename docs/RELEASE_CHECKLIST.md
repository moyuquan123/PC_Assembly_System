# PC 装机系统第一版发布清单

本清单用于封闭测试或公开发布前的逐项确认。每一项必须记录负责人、验证日期和证据链接；未完成项不得只凭口头确认跳过。

## 1. 核心产品

- [ ] 手动装机八步流程可在桌面和手机视口完成。
- [ ] 智能推荐返回均衡、性能优先和性价比优先三套方案。
- [ ] 推荐方案只包含上架配件，能够一键导入并继续调整。
- [ ] 配置总览可按八类配件和动态品牌筛选单个硬件。
- [ ] 配置方案同时展示官方方案与用户投稿，完整兼容配置可以上传并立即出现在列表中。
- [ ] 保存、复制、分享和无本地状态恢复均通过冒烟测试。
- [ ] 页面明确说明价格和兼容结果属于辅助信息。

## 2. 数据与推荐质量

- [ ] 每个配件记录规格来源、价格核验时间和图片授权状态。
- [ ] CPU、主板与 BIOS 支持关系经过人工抽样复核。
- [ ] 推荐结果覆盖三种用途和多个预算档位。
- [ ] 缺少任一类别、存在下架配件或预算过低时有明确降级提示。
- [ ] 推荐版本与兼容规则版本能够在结果中追踪。

## 3. 数据库与部署

- [ ] 从空 PostgreSQL 实例完成 migration、seed 和管理员初始化。
- [ ] migration 由独立发布任务执行，API 不在启动时修改表结构。
- [ ] 已验证历史分享在配件改价和下架后仍读取保存快照。
- [ ] 健康检查、结构化日志、备份和恢复演练均有证据。
- [ ] 镜像不包含真实密码、访问密钥或其他生产秘密。

## 4. 安全与隐私

- [ ] 生产环境没有示例管理员密码，初始密码不会在重启时覆盖现有密码。
- [ ] 管理写操作验证会话和同源请求，并记录审计日志。
- [ ] Nginx 与 API 日志不会记录完整分享码、Cookie 或密码。
- [ ] 登录失败、会话失效、非法上传和下架配件访问测试通过。
- [ ] 隐私政策说明本地草稿、匿名分析事件、日志和保留期限。

## 5. 发布验证

- [ ] `npm run validate` 全部通过。
- [ ] `npm run test:e2e` 的桌面与移动项目全部通过。
- [ ] 在 staging 执行真实 PostgreSQL、对象存储和反向代理冒烟测试。
- [ ] 记录当前 Git SHA、数据库 migration 版本、推荐版本和兼容规则版本。
- [ ] 准备应用镜像回滚方案，并确认数据库变更向后兼容。

## 6. 中国大陆公开上线前置项

- [ ] ICP 备案、HTTPS、域名和云资源主体关系已确认。
- [ ] 用户协议、隐私政策、内容来源和图片授权已完成评审。
- [ ] 分析事件遵循最小必要原则，并具备保留和删除机制。
